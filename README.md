ATM Interface

The ATM Interface is a command-line Python program that simulates ATM functionalities including authentication, balance inquiry, deposit, withdrawal, and transaction logs.

🛠️ Tech Stack
Language: Python (standard library only)
IDE: Any (VSCode, PyCharm, etc.)
Database: In-memory (no DB used)

📌 Key Features

User login simulation

Deposit and withdrawal handling

Balance check and transaction history

Console-based user interaction

🚀 How to Run the Project

Clone repo

Run ATM.py in terminal or IDE

Follow on-screen prompts to simulate ATM operations

📌 Example Modules

ATM logic with PIN entry and balance validation

Looped menu-based interaction

📄 Notes
No persistent data. Suitable for core Python beginners or simulation projects.
